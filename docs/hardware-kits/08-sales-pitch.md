## Objection handling

### “Mahal.”

- **ROI K01:** ilustrasi loss kekeringan Rp 10 jt vs kit Rp 1,8 jt ([`01-soil-monitor-kit.md`](01-soil-monitor-kit.md))
- **ROI K02:** 1× mass mortality Rp 100–500 jt vs kit Rp 4,5 jt
- **Bundle:** Smart Farm Complete Rp 10,36 jt (20% off) vs beli terpisah Rp 12,95 jt
- **OPEX:** Starter Rp 50rb/bln < 1× kopi specialty per hari

### “Kompetitor murah (Tuya / sensor Shopee).”

| Poin | Shopee / Tuya | Next-IOT kit |
| --- | --- | --- |
| Cross-domain (drone, workflow) | Tidak | Universal Mesh |
| Tambak DO + aerator rule | DIY | K02 integrated |
| LoRa plantation | Tidak native | K03 + platform |
| Pre-flash tenant + OTA | Manual | Pabrik |
| WA ops Indonesia | Plugin | Gateway tenant |

### “Butuh garansi / takut rusak.”

- Garansi **12 bulan** swap unit
- Support **WhatsApp** + dokumentasi ID
- Pro subscription: prioritas response cloud

### “Internet jelek di kebun.”

- K03 LoRa backhaul + K02 Pro 4G fallback
- Edge buffer SD (K05) snapshot sync saat online
